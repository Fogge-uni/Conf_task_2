# Вариант 5

## Этап 1

## Общее описание

На первом этапе был разработан минимальный прототип CLI-приложения на языке Java, 
предназначенного для визуализации графа зависимостей пакетов.

На данном этапе реализованы следующие функции:
- Получение настроек программы из параметров командной строки.
- Обработка имени анализируемого npm-пакета.
- Обработка URL-адреса репозитория или пути к локальному тестовому файлу.
- Поддержка режима работы с тестовым репозиторием.
- Настройка максимальной глубины анализа зависимостей.
- Настройка подстроки для фильтрации пакетов.
- Проверка корректности переданных параметров.
- Вывод всех настроек в формате «ключ — значение».
- Обработка ошибок при отсутствии обязательных параметров и передаче некорректных значений.

## Описание классов и методов
Для выполнения первого этапа были разработаны 4 класса:

- Класс `Main` является точкой входа в программу. 
В методе `main` выполняется разбор аргументов командной строки, 
проверка настроек и вывод полученной конфигурации. Для обработки ошибок используется конструкция `try-catch`.
- Класс `AppConfig` предназначен для хранения параметров запуска программы. 
В нём определены поля для имени пакета, адреса репозитория, режима тестирования, 
максимальной глубины анализа и строки фильтрации. Для получения значений используются методы `get`.
- Класс `ArgumentParser` отвечает за разбор аргументов командной строки. 
Метод `parse` определяет переданные параметры и формирует объект `AppConfig`. 
Дополнительные методы проверяют наличие значений, неизвестные и повторяющиеся параметры, 
а также обрабатывают числовое значение глубины.
- Класс `ConfigValidator` выполняет проверку корректности полученных настроек. 
Проверяется имя npm-пакета, URL репозитория или путь к тестовому файлу, максимальная 
глубина анализа и строка фильтрации.

## Описание настроек
Для настройки приложения используются пять параметров командной строки:
- `--package` — задаёт имя анализируемого npm-пакета. Является обязательным параметром.
- `--repository` — задаёт URL репозитория или путь к локальному тестовому файлу. По умолчанию используется `https://registry.npmjs.org/`.
- `--test` — включает режим работы с тестовым репозиторием. В этом режиме параметр `--repository` должен содержать путь к существующему файлу.
- `--max-depth` — задаёт максимальную глубину анализа зависимостей. Значение по умолчанию — 3.
- `--filter` — задаёт подстроку для фильтрации пакетов. По умолчанию используется пустая строка.

При запуске приложения все параметры выводятся в формате «ключ — значение».

## Описание команд для сборки и запуска тестов
Для компиляции исходного кода и запуска всех предусмотренных тестов используется файл `script.bat`.
При запуске сначала выполняется компиляция Java-файлов, после чего последовательно запускаются 15 тестовых сценариев.
Для обычного запуска уже скомпилированной программы используется `run.bat` с необходимыми параметрами.

Пример команды:
```bat
run.bat --package express
```
Пример запуска в тестовом режиме:
```bat
run.bat --package express --test --repository tests/test-repository.json
```

## Примеры использования

### Запуск программы с параметром package

```text
run.bat --package express

Параметры запуска:
package = express
repository = https://registry.npmjs.org/
test = false
max-depth = 3
filter =
```

### Запуск программы с изменённой глубиной анализа

```text
run.bat --package express --max-depth 5

Параметры запуска:
package = express
repository = https://registry.npmjs.org/
test = false
max-depth = 5
filter =
```

### Запуск программы с тестовым репозиторием

```text
run.bat --package express --test --repository tests/test-repository.json

Параметры запуска:
package = express
repository = tests/test-repository.json
test = true
max-depth = 3
filter =
```

### Пример обработки ошибок

Отсутствие обязательного параметра:

```text
run.bat --max-depth 3

Ошибка параметров: необходимо указать --package
```

Пустое имя пакета:

```text
run.bat --package ""

Ошибка параметров: необходимо указать --package
```

Некорректное имя пакета:

```text
run.bat --package "bad package"

Ошибка параметров: некорректное имя npm-пакета: bad package
```

Некорректный URL репозитория:

```text
run.bat --package express --repository invalid-url

Ошибка параметров: URL должен содержать HTTP/HTTPS-схему и имя узла
```

Отрицательная глубина анализа:

```text
run.bat --package express --max-depth -1

Ошибка параметров: глубина не может быть отрицательной
```

Нечисловое значение глубины:

```text
run.bat --package express --max-depth abc

Ошибка параметров: глубина должна быть целым числом
```

Отсутствие пути к тестовому репозиторию:

```text
run.bat --package express --test

Ошибка параметров: в тестовом режиме необходимо указать --repository с путём к файлу
```
